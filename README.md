# Документация проекта Markdown Editor and translator

## 1. Структура проекта

```
markdown editor/
  ├── Markdown_Editor.ico     # Иконка приложения
  └── Markdown_Editor.py      # Основной файл приложения
```

## 2. Описание файлов

### Markdown_Editor.py

**Назначение**: Основной файл приложения, содержащий весь код редактора Markdown.

**Ключевые классы**:
- `MarkdownEditor` - Главный класс приложения, отвечающий за создание и управление пользовательским интерфейсом
- `MarkdownEditorWidget` - Виджет редактора с подсветкой синтаксиса и нумерацией строк
- `MarkdownHighlighter` - Класс для подсветки синтаксиса Markdown
- `MarkdownRenderer` - Класс для преобразования Markdown в HTML
- `FileTreeView` - Дерево файлов для навигации по файловой системе
- `FindReplaceDialog` - Диалог поиска и замены текста
- `TranslatorDialog` - Диалог для настройки перевода документа
- `TranslatorThread` - Поток для асинхронного перевода документа

**Связи**: Файл является самодостаточным и содержит все необходимые классы для работы приложения.

**Краткое объяснение логики**:
Приложение построено на базе PyQt6 и представляет собой редактор Markdown с возможностью предварительного просмотра в реальном времени. Основной класс `MarkdownEditor` инициализирует пользовательский интерфейс, включая редактор с подсветкой синтаксиса, панель предварительного просмотра, дерево файлов, меню и панель инструментов. Редактор поддерживает основные операции с файлами (создание, открытие, сохранение), форматирование текста, экспорт в различные форматы (HTML, PDF, DOCX) и перевод документа на другие языки.

### Markdown_Editor.ico

**Назначение**: Иконка приложения, используемая для отображения в заголовке окна и на панели задач.

## 3. Библиотеки/фреймворки

| Библиотека | Назначение | Использование |
|------------|------------|--------------|
| PyQt6 | Создание графического интерфейса | Основа всего приложения, включая виджеты, окна и диалоги |
| markdown | Базовый рендеринг Markdown | Альтернативный рендеринг, если недоступен markdown-it |
| markdown-it-py | Продвинутый рендеринг Markdown | Основной рендеринг Markdown в HTML |
| pygments | Подсветка синтаксиса в коде | Подсветка блоков кода в превью |
| requests | HTTP-запросы | Используется для перевода текста через Google Translate API |
| python-docx | Работа с DOCX-файлами | Используется для экспорта в формат DOCX |
| threading | Многопоточность | Используется для асинхронного перевода документов |

## 4. Точка входа и запуск

Точкой входа в приложение является функция `main()` в файле `Markdown_Editor.py`. При запуске выполняются следующие действия:

1. Создается экземпляр `QApplication`
2. Применяется темная тема с помощью функции `apply_modern_dark_theme()`
3. Создается экземпляр главного окна `MarkdownEditor`
4. Окно отображается с помощью метода `show()`
5. Запускается цикл обработки событий приложения

Для запуска приложения необходимо выполнить команду:
```
python Markdown_Editor.py
```

## 5. Архитектурные особенности

### Нестандартные решения

1. **Собственная реализация подсветки синтаксиса Markdown**
   Вместо использования готовых решений для подсветки синтаксиса, в приложении реализована собственная система подсветки на основе регулярных выражений и `QSyntaxHighlighter`.

2. **Двойной рендеринг Markdown**
   Приложение поддерживает два метода рендеринга Markdown: через библиотеку markdown-it-py (предпочтительный вариант) и через собственную реализацию на основе регулярных выражений (запасной вариант).

3. **Асинхронный перевод документов**
   Для перевода документов используется отдельный поток (`TranslatorThread`), что позволяет не блокировать интерфейс во время длительных операций перевода.

4. **Интеграция с Google Translate API**
   Приложение использует неофициальный API Google Translate для перевода документов без необходимости использования ключей API.

### Причины выбора архитектуры

1. **Использование PyQt6**
   PyQt6 обеспечивает кроссплатформенность, богатый набор виджетов и инструментов для создания современного пользовательского интерфейса.

2. **Разделение на классы**
   Разделение функциональности на отдельные классы обеспечивает модульность, улучшает читаемость кода и упрощает сопровождение.

3. **Использование потоков для длительных операций**
   Вынесение длительных операций в отдельные потоки позволяет сохранить отзывчивость пользовательского интерфейса.

4. **Собственная реализация подсветки синтаксиса**
   Позволяет точно настроить стиль подсветки под нужды приложения и обеспечить единообразие с темой оформления.

## 7. Основные функциональные возможности

1. **Редактирование Markdown с подсветкой синтаксиса**
   - Подсветка заголовков, списков, ссылок, кода и других элементов Markdown
   - Нумерация строк
   - Подсветка текущей строки
   - Подсветка парных символов (скобки, кавычки и т.д.)

2. **Предварительный просмотр в реальном времени**
   - Отображение отрендеренного HTML в панели предварительного просмотра
   - Автоматическое обновление при изменении текста

3. **Работа с файлами**
   - Создание, открытие, сохранение файлов
   - Автосохранение
   - Список недавно открытых файлов
   - Проводник файлов для навигации по файловой системе

4. **Форматирование текста**
   - Вставка заголовков, списков, ссылок, изображений, кода и других элементов Markdown
   - Горячие клавиши для часто используемых операций форматирования

5. **Экспорт в различные форматы**
   - HTML
   - PDF
   - DOCX

6. **Перевод документов**
   - Перевод на множество языков
   - Сохранение форматирования Markdown при переводе
   - Создание многоязычной документации с автоматическим добавлением ссылок на переведенные версии

7. **Поиск и замена текста**
   - Поиск с учетом регистра и целых слов
   - Замена текста с возможностью замены всех вхождений

8. **Настройка интерфейса**
   - Темная тема оформления
   - Настройка размеров панелей
   - Сохранение и восстановление настроек между сеансами
